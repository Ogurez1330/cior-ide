# Cior IDE — онлайн-компилятор с ИИ-помощником

Рабочий учебный прототип на HTML, CSS и JavaScript с небольшим Node.js-сервером **без npm-зависимостей**.

## Запуск

1. Установите Node.js 20 или новее.
2. Откройте терминал в папке проекта.
3. Выполните `npm start` (или `node server.js`).
4. Откройте **http://127.0.0.1:3000** в браузере.

На Windows (PowerShell) включить настоящего ИИ-помощника:

```powershell
$env:OPENAI_API_KEY="ваш_ключ"
npm start
```

На macOS/Linux:

```bash
OPENAI_API_KEY="ваш_ключ" npm start
```

Можно переопределить модель переменной `OPENAI_MODEL` (по умолчанию `gpt-5.4-mini`) и порт переменной `PORT`.

## Рабочие функции

- Редактор JavaScript, Python, HTML, CSS и текста с подсветкой, номерами строк и табуляцией.
- Создание, открытие, переименование и удаление файлов (двойной щелчок — переименовать; контекстное меню — удалить).
- Автосохранение в `localStorage`, экспорт и импорт всего проекта в JSON, скачивание отдельного файла.
- Запуск **JavaScript в изолированном sandbox iframe** с выводом в консоль и остановкой по тайм-ауту.
- Запуск **Python через Pyodide** в Web Worker (первая загрузка требует доступа к CDN).
- Предпросмотр HTML + CSS из `style.css`; скрипт для страницы может быть в `script.js`.
- Чат-панель Cior AI; настоящие ответы через серверный OpenAI Responses API, если задан `OPENAI_API_KEY`. Без него показаны явно помеченные локальные подсказки, **не имитация ИИ**.
- Адаптивный интерфейс, горячие клавиши `Ctrl/Cmd + Enter` и `Ctrl/Cmd + S`.

## Важные ограничения

- Это **MVP для локального изучения и демонстрации**, не production-сервис с общими аккаунтами и облачным сохранением.
- Выполнение кода **не происходит на Node.js-сервере**. Для серверного запуска Java/C++ и других языков нужен отдельный защищённый sandbox, лимиты ресурсов, изоляция контейнеров и контроль доступа.
- Python требует интернета при первой загрузке Pyodide. Не все пакеты CPython поддерживаются; `input()` в этом прототипе не реализован.
- API-ключ никогда не должен попадать в фронтенд. Используйте переменную окружения сервера. При публикации API требуется дополнительная авторизация, учёт пользователей, квоты/ограничение стоимости и защита от злоупотреблений; встроенный IP rate-limit является только начальным барьером.
- Импорт JSON заменяет текущие файлы после подтверждения. Сохраняйте резервную копию перед импортом.
- Прототип не следует использовать для запуска недоверенного кода с конфиденциальными данными.

## Структура

- `server.js` — HTTP-сервер и маршрутизатор `/api/ai`.
- `public/index.html` — интерфейс.
- `public/styles.css` — стили.
- `public/app.js` — редактор, файловая система, безопасный запуск.
- `tests/smoke.test.js` — проверки сервера.
